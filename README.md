# SDC355-portfolio

A personal portfolio webpage built for the SDC355 JavaScript course. The page includes an About section, a dynamically rendered Projects section, a conditionally displayed Featured Content section, and a Contact form, along with a welcome modal, a hover tooltip, and a persisted Dark Mode toggle.

Live site: https://addisontech.github.io/SDC355-portfolio

## Languages & Libraries Used

- **HTML5** – page structure, semantic sections, and the contact form
- **CSS3** – all styling is written by hand in an inline `<style>` block, including the Dark Mode theme, modal overlay, and tooltip; no external CSS framework is used
- **JavaScript (vanilla, ES5-style)** – all interactivity is written in plain JavaScript with no external JS libraries or frameworks

## Features

- Custom welcome modal shown on page load, dismissible with a Close button
- About section with a skills list generated by a `for` loop
- Projects section rendered dynamically from an array of custom JavaScript objects (title, summary, image, and repo link), persisted in `sessionStorage` using `JSON.stringify()` / `JSON.parse()`
- Featured Content section that conditionally shows/hides based on the number of projects
- Dark Mode toggle with the preference saved in `localStorage` so it persists across visits
- Contact form with a hover tooltip on the Submit button and a timed confirmation message on submission

## Dependencies

None. This project has no build step, no package manager, and no external libraries. It is a single static `index.html` file that can be opened directly in any modern browser or served through GitHub Pages.

## Running the Page

1. Clone or download this repository.
2. Open `index.html` directly in a browser, or visit the GitHub Pages link above.

No installation or setup is required.
